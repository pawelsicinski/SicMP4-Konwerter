Autoryzacja YouTube (cookies.txt)

Wymagane na serwerach chmurowych (Render / VPS), których adresy IP blokuje YouTube

Jak prawidłowo wyeksportować cookies.txt (zgodnie z dokumentacją yt-dlp):

  1. Otwórz nowe okno Incognito / Prywatne w przeglądarce i zaloguj się na konto YouTube.
  2. W tym samym oknie otwórz https://www.youtube.com/robots.txt i wyeksportuj plik rozszerzeniem Get cookies.txt LOCALLY.
  3. Od razu zamknij okno Incognito (aby przeglądarka nie nadpisała tokenów sesji) i wgraj plik poniżej lub wklej go na stałe w panelu Render (Environment -> Secret Files -> cookies.txt).
